P1
La opción -n del comando revert es para que una vez
recuperado el archivo podamos hacer nosotros el commit.
Si no el commit se haría automaticamente, es para evitar que el nuevo revert te genere un commit adiconal.


P2 
Como no se ha realizado ningun add no se produce ningún cambio.
Si hubiera algun add, se hubiera borrado

P3
La diferencia es que el revert deshace el ultimo commit y
reset te lo borra todo hasta el ultimo commit.
